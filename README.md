# Pac-Man-game
Pac-Man Game

A simple Pac-Man clone built using HTML, CSS, and JavaScript.  
This is my first coding project.

## 🎮 How to Play
- Use the arrow or WASD keys to move Pac-Man.
- Collect all the pellets.
- Avoid the ghosts!
